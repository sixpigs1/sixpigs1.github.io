# Image Placeholders

This directory contains image placeholders for the website.

## Required Images

### Profile
- `profile.jpg` - Your profile photo (250x250px recommended)

### Publications
- `publications/sample1.jpg` - Publication preview images
- `publications/sample2.jpg`
- Add more as needed

### Awards
- `awards/scholarship.jpg` - Award certificate images
- `awards/robotics-competition.jpg`
- `awards/national-scholarship.jpg`
- Add more as needed

### Journey
- `journey/club1.jpg` - Journey experience images
- `journey/club2.jpg`
- `journey/volunteer1.jpg`
- `journey/project1.jpg`
- `journey/project2.jpg`
- Add more as needed

## Image Guidelines

- Use high-quality images (at least 1200px width for publications)
- Keep file sizes reasonable (< 500KB per image)
- Use JPEG for photos, PNG for graphics with transparency
- Follow naming conventions: lowercase, hyphen-separated
